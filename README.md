A complete beginner-friendly tutorial to learn **Excel VBA (Visual Basic for Applications)** through a **real-world Supply Chain example**.


## 🎯 Objective

Learn how to automate Excel spreadsheets using **VBA** to perform professional analytics in a **Supply Chain context**.

This project simulates the work of a **Solution Design Manager** automating warehouse sizing and costing scenarios during RFPs (Request for Proposals).

## 🧠 What You’ll Learn

- How to create your first VBA **macro**
- How to **declare variables**, use **loops**, and apply **conditions**
- How to read and update **Excel cells** from VBA
- How to add **error handling** and optimize performance
- How to automate **multiple scenarios** for warehouse operations

## 📦 Installation

1. Download and extract either `.zip` file.
2. Open the Excel file inside with **Microsoft Excel** (Windows or Mac).
3. Enable **Macros** and **Developer Mode** if prompted.
4. Open the **VBA Editor**:
   - Press `Alt + F11`
   - Open the module to view the VBA code


## 🧩 Key VBA Concepts Covered

| Concept | Description |
|----------|-------------|
| `Option Explicit` | Enforces variable declaration for safer debugging |
| `For / Next` loops | Automate row-by-row or column-by-column processing |
| `If / Else` statements | Add conditional logic to control calculations |
| `MsgBox` | Display alerts or debugging messages |
| `Error Handling` | Catch runtime errors using `On Error GoTo` |
| `Application.Calculation` | Optimize performance by controlling automatic recalculation |
